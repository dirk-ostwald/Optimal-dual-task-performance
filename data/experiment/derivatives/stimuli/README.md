                                                                  # FCDT stimulus catalogue

`stimuli.csv` maps stable task-specific integer identifiers to the concrete
stimuli used in the four component tasks. Image paths are relative to this
directory. Text stimuli have an empty `stimulus_file` value.

Column `fixed_label` implements the binary stimulus label when it is fixed by
the task. Label 1 denotes the positive stimulus category and label 0 denotes the
complementary category. The value is empty for PTD and LTD because target
membership is participant- and block-specific.

The catalogue is generated by `code/abm_preparation.py` from the source stimulus
material. It contains 18 PTD patterns, 190 unordered LTD letter pairs, 8 DPC
digit pairs, and 8 RMC object pairs.
